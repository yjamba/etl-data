# etl-data
Высоконагруженный ETL-конвейер: Агрегатор крипто-сделок в реальном времени

etl-data-pipeline/
├── cmd/
│   └── main.go                 # Точка входа, DI-контейнер, инициализация Graceful Shutdown
├── internal/
│   ├── domain/                 # Чистый бизнес-слой (без внешних зависимостей)
│   │   └── accesslog/          # Предметная область - логи доступа
│   │       ├── log.go          # Структура сущности LogEntry (IP, HTTP-статус, метод) и правила валидации
│   │       └── repository.go   # Интерфейс (Порт) LogRepository для сохранения данных
│   ├── application/            # Слой оркестрации (Use Cases)
│   │   └── pipeline/
│   │       └── processor.go    # Логика Fan-Out/Fan-In, запуск воркеров-парсеров, батчинг
│   └── infra/                  # Слой адаптеров (взаимодействие с внешним миром)
│       ├── nginx/
│       │   └── tail_reader.go  # Адаптер чтения лог-файла в реальном времени (генератор строк)
│       ├── geoip/              # (Опционально) Адаптер для определения страны пользователя по IP
│       │   └── maxmind.go
│       └── postgres/
│           └── repository.go   # Имплементация LogRepository: сохранение разобранных логов в БД
├──.gitignore
└── README.md
